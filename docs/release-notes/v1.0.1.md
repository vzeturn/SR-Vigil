## Vigil 1.0.1

### New
- **Suspicious network behaviour**: a program that calls one Internet address at a regular rhythm (beaconing, typical of backdoors and trojans) is flagged from connection timing alone. Traffic is never decrypted or read. Vigil asks you before anything about it is sent to the AI advisor: **Ignore**, **Analyze with AI** or **Block** ([docs/24](https://github.com/vzeturn/SR-Vigil/blob/main/docs/24-suspicious-network-behaviour.md)).
- **Hourly re-check** of running programs, so a file that changed or gained new evidence is re-judged without a restart.
- **Navigation**: the sidebar is grouped into Monitor, Respond and Review, with Settings at the foot.

### Fixed
- Pressing **Trust** (an allow decision) now updates the live verdict immediately, and revoking it withdraws it.
- Vigil's own binaries are always trusted (HA-001) and never listed as Unknown.

### Install
1. Download `Vigil-1.0.1.msi` and its `.sha256`.
2. Verify: `(Get-FileHash Vigil-1.0.1.msi -Algorithm SHA256).Hash` must equal the `.sha256` value.
3. Run the MSI as administrator. It upgrades 1.0.0 in place; data in `%ProgramData%\Vigil` is kept.

An SBOM (CycloneDX) is attached.

### Notes
- This build may be unsigned; Windows SmartScreen can warn until signing and reputation are in place.
- Beaconing detection keeps its state in memory and starts fresh when the service restarts; connections shorter than about 500 ms can be missed (tracked in `docs/10`).
- No telemetry and no auto-update. Network use is limited to the endpoints listed in `CLAUDE.md` rule 10.
