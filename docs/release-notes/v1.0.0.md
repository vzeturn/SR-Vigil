## Vigil 1.0.0

Windows endpoint tool that classifies every process and network connection as Safe, Unknown or Malicious, enforces policy, and can ask Claude for a second opinion. User-mode only, no driver.

### Highlights
- **Verdicts with evidence**: Malicious requires a hard rule or advisor/reputation evidence; a low score alone is Unknown.
- **Enforcement** (`observe`, `learning`, `enforce`): WFP filters, process termination with a never-kill guard, hash-chained audit log, reversible persistence clean-up.
- **Lockdown**: stops untrusted background programs for 5 minutes; signed, advisor-cleared tools and AI agents are spared.
- **URL filter** (opt-in): local DNS sinkhole fed by public malware, phishing, adult and ad lists; fails open and restores DNS on stop.
- **Pause protection**: one switch stops all automatic blocking and killing; assessments stay live. `vigilctl protection on|off`.
- **AI advisor** (optional): Anthropic API with your key (DPAPI-encrypted) or the shared endpoint; it can never override a hard rule.
- **Tray UI** (Tauri) and `vigilctl` CLI over an authenticated named pipe.

### Install
1. Download `Vigil-1.0.0.msi` and its `.sha256`.
2. Verify: `(Get-FileHash Vigil-1.0.0.msi -Algorithm SHA256).Hash` must equal the `.sha256` value.
3. Run the MSI as administrator. The service is `VigilSvc`; data lives in `%ProgramData%\Vigil`.

An SBOM (CycloneDX) is attached.

### Notes
- This build may be unsigned; Windows SmartScreen can warn until signing and reputation are in place.
- Browser DNS-over-HTTPS bypasses the URL filter.
- No telemetry and no auto-update. Network use is limited to the endpoints listed in `CLAUDE.md` rule 10.
